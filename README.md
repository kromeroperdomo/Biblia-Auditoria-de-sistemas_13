# 📖 Biblia de Auditoría de Sistemas - Grupo 13

Aplicación web progresiva (PWA) de consulta rápida diseñada exclusivamente para auditores de sistemas. La herramienta estructura y filtra de manera ágil los controles, evidencias y técnicas de auditoría del **Marco Legal Colombiano aplicable a TI y NIIF**.

## 🔗 Enlace de Despliegue (Live Demo)
👉 [Haz clic aquí para ver la aplicación en vivo](https://kromeroperdomo.github.io/Biblia-Auditoria-de-sistemas_13/)
## 🎯 Alcance y Funcionalidades
*   **Índice Interactivo:** Panel de consulta con 25 palabras clave estratégicas divididas en 5 dominios (Privacidad, Delitos Informáticos, Comercio Electrónico, Propiedad Intelectual y NIIF).
*   **Búsqueda Dinámica:** Motor de búsqueda relacional que filtra en tiempo real las fichas normativas sin necesidad de recargar la página.
*   **Fichas Ejecutivas:** Tarjetas de auditoría sintetizadas que exponen la norma, el objetivo de control, la evidencia esperada, la prueba técnica recomendada y el riesgo asociado.
*   **Modo Offline:** Arquitectura PWA que permite la consulta de la base de datos normativa en entornos sin conexión a internet.

## 🛠️ Stack Tecnológico
*   **Frontend:** HTML5, CSS3 (Vanilla)
*   **Lógica y Motor de Búsqueda:** JavaScript (ES6)
*   **Base de Datos:** Estructura JSON local (`normatividad.json`)
*   **Arquitectura:** PWA (Progressive Web App)
